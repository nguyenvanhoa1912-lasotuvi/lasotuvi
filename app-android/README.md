# App Android "Cúm & Giá Gia Cầm"

- 3 tab: Cúm gia cầm Việt Nam · Cúm gia cầm thế giới · Giá gia cầm (trang GitHub Pages).
- Mở app: tự quét ngay; trong app tự quét lại 1 lần/ngày.
- Quét nền 1 lần/ngày (kể cả khi không mở app): báo khi có bảng giá gà mới hoặc tin cúm gia cầm mới.
- Build tự động: `.github/workflows/app-android.yml` → file APK ở mục Releases.
- Tải bản mới nhất: https://github.com/nguyenvanhoa1912-lasotuvi/lasotuvi/releases/latest/download/CumGiaCam.apk
